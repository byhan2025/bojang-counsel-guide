# 보장분석 · 5대 우선순위 상담 가이드

손해보험 설계사(FC)가 현장 상담에서 바로 쓰는 모바일 웹앱(PWA)입니다.
빌드 도구 없이 Vanilla HTML/CSS/JS로 동작하고, 홈 화면에 추가하면 앱처럼 열립니다.

## 구성

| 탭 | 내용 |
| --- | --- |
| 📋 보장분석 | 고객 정보 입력 → 5대 우선순위 자동 진단(적정/보강 필요/공백 위험), 보장 구멍·보험료 다이어트 체크, 리모델링 3단계, **고객 카톡 요약 복사** |
| 🎯 5대 담보 | 1.암 → 2.뇌 → 3.심장 → 4.수술비 → 5.간병비. 담보별 4단 구조(보장 범위 비교 · 1분 설명 화법 · 증권 분석 함정 · 청구·약관 주의) |
| ⚡ 현장 툴킷 | 고지의무 3·1·5 체크표, 간편심사 3·2·5 비교, 실손 1~5세대 비교표(2026.11 개편 포함), 반론 돌파 화법(공감→환기→대안) + 원터치 복사 |

## 파일

```
index.html      화면 구조
styles.css      디자인(네이비·화이트·민트, 모바일 퍼스트)
content.js      상담 콘텐츠 데이터(담보 가이드·고지의무·실손 세대·반론 화법)
app.js          진단 로직·렌더링·복사
manifest.json   PWA 매니페스트
sw.js           서비스 워커(앱 셸 캐시 → 오프라인 동작)
icons/          앱 아이콘(192·512·maskable·apple-touch)
```

## 진단 기준

- 5대 담보 권장선(연령대별) 대비 보유 금액으로 `적정 / 보강 필요 / 공백 위험`을 판정합니다.
- 수술비는 5종 수술비 금액 + N대 수술비 보유, 간병비는 간병인 사용일당 + 장기요양 보장 보유를 함께 봅니다.
- 보험료 다이어트는 실손 세대, 갱신형·적립형·특약 수, 연 보험료 대비 핵심 진단비 배수로 체크포인트를 만듭니다.
- 권장선은 상담 보조용 참고값이며, 실제 지급 여부·금액은 가입한 상품의 약관과 증권이 기준입니다.
