### 3) 현장 UX · 카피 · 연령대별 기준선
- **결론 한 문장 배너**: 결과 최상단에 `보완 후보 담보 N개, 가장 시급한 것은 OO` (0개일 때는 "보완 후보 담보 0개 — 5대 담보가 기준선을 충족합니다. 추가 가입보다 갱신·만기 점검을 권장합니다.")를 고정 표시합니다.
- **용어 통일**: `부족·위험·미달` 판정 표현을 **`보완 후보`** 로 바꾸고, 단정 대신 **`확인 권장`** 어미를 씁니다. 배지는 색상 단독이 아니라 **색상 + 텍스트**를 함께 씁니다.
- **복사 피드백**: 카톡 초안·화법 복사 버튼이 **'복사됨 ✓' 상태로 전환**되고(1.6초), 토스트가 함께 뜹니다. 클립보드가 막히면 실패를 분명히 알립니다.
- **글자·터치 하한**: 고객 화면 본문 **12px 이상**, 보조 설명 **11px 하한**, 9~10px은 소형 라벨(.eyebrow·badge·rank)에만 허용. 주요 터치 대상은 **최소 높이 44px**.
- **연령대별 권장 기준선**: 20~30대 / 40~50대 / 60대+ 로 암·뇌·심장·수술·간병 권장액을 나누고(40~50대는 기존 사용자 기준점 유지), 5대 진단 카드 밑에 **기준일(2026-11-17)과 출처(국가암등록통계 2023 · 통계청 2024 사망원인통계 · 심평원 진료비통계 · 건보공단 노인장기요양 통계연보)를 한 줄로 고정**했습니다. 통계 기준을 세울 수 없는 항목(재진단 보장·간병 요건 등)은 `std:false` 로 **색 판정에서 제외**합니다.

### 4) PDF 텍스트 레이어 · 보안 · 서비스워커 · CI
- **PDF 실제 텍스트 레이어**: Canvas JPEG 위에 **Type0/Identity-H + ToUnicode CMap** 보이지 않는 텍스트(Tr 3)를 얹었습니다. 레이아웃·시각 품질은 그대로이고, `pymupdf`로 1·10·30장 모두 **실제 한국어·숫자가 추출**됩니다(테스트 실측). **고객 실명은 파일명·문서 제목에서 기본 제외**하고 `#pdf-include-name` 토글을 켤 때만 들어갑니다.
- **보안 마감**: `app.js` 결과 히어로의 고객명 등 innerHTML 동적 삽입부를 이스케이프하고, **CSP 메타**(default-src 'self' data: blob:, object-src 'none', base-uri 'self')를 추가했습니다. 기기 저장은 **WebCrypto AES-GCM**(IndexedDB의 추출 불가 CryptoKey)으로 암호화하고, **'민감정보 미저장(세션 전용)'** 토글·**로그아웃 시 로컬 삭제** 선택·**지금 삭제** 버튼을 더했습니다.
- **v7.1.1 후속 2건**: `backend.js` 목적지 가드를 **HTTPS + 기본 포트 443만** 허용하도록 잠갔고(http:·:8443 차단), OCR 안내를 `ocr.js` 단일 출처로 모아 **OpenAI 경로(단일 모델) / Gemini 경로(최대 4개 모델 후보)** 로 분리 표기했습니다.
- **서비스워커 캐시 분리**: `/functions/v1/`·`/rest/v1/`·`/auth/v1/`·상담기록·`.pdf` 경로는 캐시에서 제외하고, `cache.addAll` 대신 **파일별 cache.add 실패 격리**로 바꿨습니다(한 파일 실패로 설치 전체가 깨지지 않음).
- **GitHub Actions CI**: `.github/workflows/bojang-ci.yml` — push/PR에서 단일 HTML 빌드, 핵심 테스트(v5.9·v6.1·v6.2·v7.0·v7.1·v7.2), PDF 스모크(페이지 수·텍스트 추출)를 자동 실행합니다.

## v7.1.1에서 달라진 것 — 회의실 4호 봇·부이 대리 지적 6대 결함 완결 패치

v7.1의 구조(공공데이터 F 카드·다음 할 일 띠·30장·PDF)는 그대로 두고, 지적받은 6건만 정확히 고쳤습니다.

1. **암·유사암 진단비 필수서류 보완**: `C73`(갑상선암 등)에서 진단서만 체크해도 '서류 준비됨'이 나오던 결함을 고쳤습니다. 암·유사암 진단비 후보 담보는 **진단서 + 병리조직결과지**가 모두 있어야 준비됨으로 바뀌고, 진단서만 있으면 '서류 더 필요 · 빠진 서류 — 병리조직결과지'로 표시됩니다.
2. **프록시 자유 입력 전송 차단**: 검색어 앞 40자를 그대로 GET 으로 보내던 경로를 없앴습니다. **내장 사전에서 정확히 확인된 표준 약 이름(성분명)만** 프록시로 나가고, 사전에 없는 자유 입력은 **외부 요청 0회**로 차단합니다. 프록시 안내는 360px에서 두 줄 요약만 보이고, 상세(Cloudflare·국외 이전·5분 캐시·참고용 한계)는 `<details>` 접기로 넣었습니다.
3. **백엔드 목적지 allowlist(fail-closed)**: 화면 가드를 통과해도 목적지 호스트가 공식 목록(`ntfhdiujapctomzzaifu.supabase.co`·로컬 검증)이 아니면 **설정이 바뀌어도 요청을 보내지 않습니다**(`host-lock`). 로그인·동기화·연결 테스트·AI 비전·결제 모두 같은 검사를 거칩니다.
4. **표지 보장 가치 문구 복원 + 세로 넘침 0**: 430px 이하에서 숨기던 `.cover-values`를 다시 보이게 하고, 간격을 압축해 **360×740에서도 스크롤 없이 한 장**으로 들어가게 했습니다. `reports/bojang-guide/v7.1/ui-cover-no-overlap.png`를 재촬영했습니다.
5. **공휴일 보정 문구 분리**: 직전·다음 영업일은 **"운영상 연락·서류 접수 참고일"**이며 **실제 보장개시일·효력일·상령일은 보험사 약관 기준**이라고 명시했습니다(`publicdata.js`·`aftercare.js`·다음 할 일 띠).
6. **OCR 모델 후보 문구 정확화**: Edge Function 실코드에 맞춰 "최대 3회 재전송"을 **"OpenAI 경로 또는 사용자 지정 Gemini 포함 최대 4개 모델 후보"**로 고쳤습니다(`app.js` 개인정보처리방침·데이터 흐름 도식, `index.html` 촬영 안내).

## v7.1에서 달라진 것 — 공공데이터(k-skill) 실무 연동 · 이 고객 다음 할 일 · v7.0 실물 검수 결함 3건

v7.1은 **상담 책상 위의 공공데이터**를 앱 안으로 가져온 회차입니다. 보장분석·30장·PDF 엔진과 첫 화면 3버튼·오프라인 단독 동작은 v7.0 그대로이고, 더한 것은 현장 툴킷 `F · PUBLIC DATA`와 결과 화면의 한 줄 띠입니다.

### 1) 공공데이터 실무 연동 (현장 툴킷 `F · PUBLIC DATA`) — 기본 100% 오프라인
- **F-1 복용약 고지 누락 체크**: 성분·대표 브랜드 **70여 개 내장 사전**(아스피린·메트포르민·암로디핀·리바로·씬지로이드·자렐토·졸피뎀·마운자로 등)으로 약 이름을 넣으면 질환군과 KCD, 3개월 투약·상시 복용·5년 30일 투약·5년 10대 질병 문항을 `지금 확인 / 확인 필요 / 지난 기간`으로 갈라 보여 줍니다. **"약만으로 고지 대상이 되지는 않습니다"** — 처방 사유가 된 질환과 기간이 문항을 가린다는 경고를 항상 함께 띄웁니다. 영양제·처방 없는 일반약은 대상 아님으로 분리했습니다.
- **F-2 이 고객 맞춤 공식 통계 + 약관 괴리**: 통계청 2024 사망원인 · 중앙암등록본부 2023 · 중앙심뇌혈관질환센터·건보 2023 · 건보공단 2025 노인장기요양을 고객의 연령대·성별·가족력에 맞춰 카드로 재배열하고, **모든 카드에 `출처 · 기준연도 · 대상 범위`를 한 줄로 고정 표기**합니다. 별도 블록에 **공공 진료통계(I65·I66·I20) ↔ 민영보험 약관(뇌졸중·급성심근경색) 괴리 5건**을 `공공 통계 / 약관 기준 / 현장 확인` 3단으로 병기했습니다.

## v6.0에서 달라진 것 — 핸드폰 = 마스터 스마트키 · 계정 잠금 · 서버 보안 2차

핸드폰을 **마스터 스마트키**로 만들어 PC 화면을 QR로 열고, 잃어버렸을 때는 폰에서 1탭으로 잠급니다.
아이폰·안드로이드 **공통 웹 표준만** 씁니다(안드로이드 전용 `BarcodeDetector` 사용 안 함, 외부 CDN 0).

### 1) PC 화면 — 「스마트키로 PC 열기」
- 메뉴 `더보기 → 🔑 스마트키로 PC 열기` 를 누르면 PC RAM 에서만 **임시 ECDH·ECDSA 키쌍**을 만듭니다(개인키는 메모리에만 있고 어디에도 저장·전송되지 않음).
- 서버(또는 모의 릴레이)가 **1회용 challenge** 를 발급합니다: `6자리 코드` · `2자리 확인 숫자(00~99)` · **180초 카운트다운** · QR(`qr.js` 자체 렌더).
- QR을 새로 고치면 이전 코드는 즉시 `replaced` 로 무효화되고, 승인은 **한 번만** 됩니다.

### 2) 폰 화면 — 「PC 연결 (이 폰으로 승인)」
- **1순위 카메라 스캔**: `getUserMedia` + **자체 순수 JS QR 디코더**(`qrscan.js`). 아이폰 Safari·안드로이드 크롬 모두 같은 코드로 동작합니다.
  - 파인더 패턴 검출 → 원근 보정 샘플링 → 포맷 정보 → 언마스크 → 리드솔로몬 오류정정(버전 1~10)까지 직접 구현했습니다.
- **2순위(항상 동작하는 폴백)**: QR 아래 **6자리 코드 직접 입력**. 카메라 권한 거부·구형 브라우저·화면 반사 등 어떤 상황에서도 인증이 막히지 않습니다.
- 승인 화면에는 **PC 기기명 · 접속 시각 · 공식 도메인 · 2자리 숫자**와 **같은 크기의 [거절] / [승인]** 버튼을 나란히 보여 줍니다(PC 화면 숫자와 다르면 거절).
- 승인 인증은 `https` 에서 **WebAuthn**(아이폰 Face ID · 안드로이드 지문), `file://`·미지원 브라우저에서는 자동으로 **PIN(4~6자리)** 으로 분기합니다. 생체인증이 실패해도 PIN으로 계속할 수 있습니다.
- 승인되면 폰이 상담 요약을 **PC 공개키로 AES-GCM 암호화**해 보내고, 서버는 암문만 중계합니다(복호화 키 없음). PC는 자기 개인키로만 열 수 있습니다.

### 3) 서버 검증 (릴레이 방어)
`qr-auth-approve` 는 아래를 **모두** 통과해야 세션을 발급합니다.
1. 폰 JWT (`requireUser`) 2. 등록된 **마스터 휴대폰** 3. **폰 기기 개인키 서명**(`SMK1|approve|challenge|code2|pc_pub_hash|device|issued_at`)
4. **180초 만료** 5. **단회 원자적 소비**(`update … where status='pending' and expires_at>now()`)
6. **`pc_pub_hash`·확인 숫자 일치** — 다른 PC로 갈아끼우는 릴레이를 차단합니다.
PC가 challenge를 낼 때도 자기 키로 `pc_sig` 를 만들어 보내므로, 위조된 공개키를 밀어넣을 수 없습니다.

### 4) 계정 잠금 · 기기 바인딩 · 원격 잠금
- **최대 2기기**: 마스터 휴대폰 1 + PC 1. 새 PC를 붙이면 **1탭 「기존 PC 밀어내기」** 로 기존 PC 세션을 즉시 무효화하고 교체합니다(본인 잠김 방지).
- **원격 잠금**: 기기 관리에서 연결된 PC의 **[원격 잠금]** → 활성 PC 창은 1.5초 안에 잠금 화면으로 바뀌고, 닫았다 다시 열어도 세션이 무효라 들어갈 수 없습니다.
- **자동 잠금**: 자리를 비우면(기본 3분, 1·3·5·10분/끔 선택) PIN·생체 잠금. 화면 오른쪽 아래 🔒 버튼으로 즉시 잠글 수도 있습니다. 5회 실패 시 30초 지연.
- **고객 앞 프라이버시 가림 모드**: 고객용 30장 화면에서 고객명을 `홍*동님` 으로, 전화번호·주민번호 뒷자리를 가립니다. **상담 화면은 그대로 유지**되며, 좌측 하단 칩으로 즉시 켜고 끕니다.

## v5.8에서 달라진 것 — 클라우드 동기화 · 고지의무 체크 · 카톡 요약 · 사진 AI 직접 기재 담보 · QR 46pt

"실전 완성" 단계입니다. v5.7까지 화면·PDF에 있던 것을 **다른 기기에서 이어 쓰고, 현장에서 1탭으로 꺼내 쓰는** 쪽을 마무리했습니다.

### 1) 클라우드 상담 기록 동기화 — PC에서 저장, 아이폰에서 열기
- `상담 저장`을 누르면 `localStorage`와 **동시에 Supabase `consultations` 테이블에 upsert**합니다.
  - 서버 행 `id` 는 `user_id + 로컬 상담 id` 의 **결정적 UUID**(SHA-256)라, 같은 상담을 다시 저장해도 새 행이 생기지 않습니다.
  - 저장 스냅샷은 `input_json`(연령대·5대 담보·직접 기재·계약·고지 체크) + `result_json`(점수·등급)뿐이며 **증권 이미지·주민번호는 올리지 않습니다.**
- 로그인하면(`afterAuth`) 최근 상담 20건을 내려받아 **최근 상담 목록에 ☁ 배지**로 합칩니다. 다른 기기에서 저장한 상담을 눌러 `불러오기` → 입력값·점수가 그대로 복원됩니다.
- 홈·분석 화면의 **`☁ 클라우드에서 불러오기`** 버튼으로 언제든 수동 동기화할 수 있고, 옆 칩이 연결 상태(`기기 + 클라우드 저장` / `이 기기에만 저장`)를 보여줍니다.
- **테이블 미적용 프로젝트 폴백**: `consultations` 가 없는 프로젝트에서는 자동으로 기존 `clients` 테이블 `payload` 에 상담 스냅샷을 저장해 **오늘 바로 이어보기가 동작**합니다(응답 코드 `PGRST205` 감지). 새 스키마는 `supabase/migrations/002_consultations.sql`(멱등 DDL + RLS + `(user_id, local_id)` 유니크 인덱스) 한 번 실행이면 켜집니다.
- 미로그인·오프라인·요청 실패 시에는 **아무 오류도 띄우지 않고** 로컬 저장만 남습니다.

## v5.6에서 달라진 것 — 증권 담보 직접 기재 (통합형 · 개별형)

보험사마다 뇌·심장 주요치료비를 **하나로 묶어 파는 곳(통합형)** 과 **개별로 나눠 파는 곳(개별형)** 이 달라, 고정 칸에 담기지 않는 특약을 증권 담보명 그대로 적을 수 있게 했습니다.

### 1) 데이터 모델 — `state.cov.custom`
- `custom = { cancer: [], brain: [], heart: [], surgery: [], care: [] }`, 항목은 `{ id, name, amount(만원), mode: 'bundle'(통합형) | 'individual'(개별형), note }`.
- `custom` 이 비어 있으면 **점수·판정·요약·체크포인트·PDF 문장이 v5.5와 100% 동일**합니다(회귀 유지, 테스트로 고정).
- `normalizeState()` 가 5개 영역 배열을 항상 보장하고, 이름/금액/모드를 정규화합니다. `localStorage` 세션·상담 저장·JSON 내보내기/가져오기에 그대로 보존됩니다.

### 2) 계산 반영 — 치료비 축 · 충족도 · 담당자 소견
- 암 주요치료비 5종·뇌·심장 주요치료비 3종(세부 칸이 있는 영역)은 **담보명 키워드로 칸을 찾아** 금액을 합산합니다(예: `혈전용해치료비`→혈전용해, `관상동맥성형술(스텐트)`→수술, `표적항암약물허가치료비`→항암약물).
- **통합형**은 하나의 담보가 여러 치료를 함께 지급하는 상품으로 보고 **세부 권장액 비율로 나눠** 반영합니다. 세 칸이 모두 비어 있어도 `순환계 주요치료비(통합) 2,000만원`을 넣으면 치료비 축이 인정됩니다.
- **진단비 이름**의 담보는 치료비 축에 더하지 않고 표시만 합니다. 각 칸은 권장액까지만 점수에 반영되고, 금액 합계 표시에는 실제 금액이 나옵니다.
- 수술·간병 영역은 고정 6축 판정을 그대로 두고, 직접 기재 담보는 증권 확인용으로 표시합니다.
- `checkpoints()`(보장 구멍)·`summaryOf()`(현재 보장 문장)도 실효값(eff)으로 판단해, 통합형으로 채운 칸을 "없음"으로 잘못 짚지 않습니다.

### 3) 입력 UI — 영역별 직접 추가 · 프리셋 · 모바일 360px

- 헤더 **플랜 배지(무료 체험 / PRO)** 와 메인 **요금제 배너**에서 상태를 확인하고, 배지를 누르면 **요금제·페이월 모달**이 열립니다. 모달에서 `Pro 체험 켜기(데모)`를 누르면 잠금이 즉시 풀리고, Pro 상태에서는 `무료 체험으로 돌아가기`로 되돌립니다.
- **Free 범위**: 5대 담보 진단·기본 입력 / 고객 1명 저장 / 30장 슬라이드 **1~6번 요약만** / **1장 요약 PDF만**(하단 `보험에 반하다 · 무료 체험판` 워터마크) / 질병코드 상위 3개 맛보기 / 청구 서류 열람.
- **잠금 동선**: 7번부터 30장은 **블러 + `🔒 Pro 멤버십으로 30장 전체 열기` 카드**, 10·30장 PDF 버튼은 🔒 표시 후 페이월, 고객 2명째 저장·질병코드 상세/복사·청구 복사·리모델링 After·브랜드 저장에서도 같은 페이월이 뜹니다. 페이월에는 **Free vs Pro 비교표 · 월/연 구독 카드 · Pro 체험 켜기(데모)** 가 있습니다.
- **Pro 범위**: 30장 전체 · 1/10/30장 PDF 무워터마크 · 고객 30명 저장 · 리모델링 전체 · 화이트라벨 저장.

### 2) 리모델링 Before / After 비교기 (메뉴 13)
- 보유 계약을 `유지 / 감액 / 정리(해지)` 로 고르고, 담보별 **보강 후 금액·예상 추가 보험료**를 입력하면 **월 보험료 변화(예: 27 → 22만원, -5만원 절감)** 와 **종합 점수 변화(79 → 81, +2점)** 가 실시간 계산됩니다.
- 5대 담보 Before/After 막대·비교표, **설계사 한 줄 제안 자동 작성**, **리모델링 1장 비교 PDF**(브랜드 표지·꼬리말 포함)와 **카톡 요약 복사**를 지원합니다.
- 권장선을 이미 넘은 담보는 `이미 권장선 이상`으로 표시해, 금액을 더 넣어도 점수가 오르지 않는 이유를 보여줍니다.

### 3) 화이트라벨 (메뉴 14 · 내 브랜드 설정)
- **상호 / 브랜드명 · 서브 슬로건 · 설계사 이름·직함·연락처·상담 카톡 링크 · 포인트 테마 4종**(보험에 반하다 로즈 / 신뢰 네이비 / 모던 에메랄드 / 클래식 차콜).
- 저장하면 **앱 헤더 · 메인 허브 · 고객 30장 표지 · 1/10/30장 PDF 표지와 꼬리말**에 즉시 반영됩니다. Free는 미리보기만 되고 저장은 페이월입니다.
- PDF는 상호를 앞말(먹색)·끝말(포인트)로 나눠 그리고, 표지 오른쪽에 설계사 연락처, 꼬리말에 브랜드명을 남깁니다.

- 현 데모의 `localStorage['bojang.plan.v1']` 은 시연용이며, 상용에서는 서버 `entitlements` 응답이 유일한 판단 근거가 되도록 교체 지점을 표로 정리했습니다.

## v5.0에서 달라진 것 — 「보험에 반하다」 브랜드 에디션 + 뇌·심장 진단비 3단계 + FC 실무 도우미 4종

### 1) 뇌·심장 진단비 금액 입력 (가장 중요한 누락 보완)
기존에는 뇌·심장에 '보장 범위(코드)' 선택과 주요치료비 3종만 있었고 **진단비 금액 입력이 없었습니다.** 실제 증권은 범위별로 금액이 따로 가입돼 있어, 세 칸(뇌) / 두 칸(심장)을 각각 입력하도록 바꿨습니다. 각 칸 0~5,000만원, 칩 `없음 / 1,000 / 2,000 / 3,000 / 5,000` + 직접입력.

- **뇌**: 뇌혈관질환 진단비(I60~I69, 핵심·권장 2,000) · 뇌졸중 진단비(I60~I63·I65~I66, 뇌경색 I63 포함) · 뇌출혈 진단비(I60~I62, 가장 좁은 범위)
- **심장**: 허혈성심장질환 진단비(I20~I25, 핵심·권장 2,000) · 급성심근경색 진단비(I21~I23, 협심증 I20 제외)
- 아래에 기존 주요치료비 3종(혈전용해제·수술·중환자실) 유지.
- **포함관계·합산 계산**: 뇌경색(I63) = 뇌혈관+뇌졸중 (뇌출혈 0원), 뇌출혈(I61) = 세 담보 합산, 뇌혈관 후유증(I69) = 뇌혈관만. 협심증(I20) = 허혈성만, 급성심근경색(I21) = 허혈성+급성심근경색. 입력 화면·30장 슬라이드·PDF에 **진단 시 합산 금액**을 코드별로 표시합니다.
- **범위 공백 경고**: 좁은 범위만 있고 넓은 범위(뇌혈관·허혈성)가 0원이면 `⚠ 범위 공백 경고 — 협심증·뇌경색 미보장`을 입력 카드·진단 체크포인트·슬라이드·PDF에 명시합니다.
- 점수는 **가장 넓은 범위를 주축**으로 평가하고, 좁은 범위만 있으면 부분 점수만 줍니다(예: 뇌출혈 2,000만원만 있으면 30% 수준).
- 기존 `cov.brain.scope`/`cov.heart.scope` 세션은 오류 없이 진단비 2,000만원으로 이관하고 마이그레이션 안내를 남깁니다.

### 2) 브랜드 디자인 전면 개편 — 「보험에 반하다」
- 타이틀 **보험에 반하다** + 슬로건 `당신의 삶에 꼭 맞는 보험, 현명한 선택`, 4대 가치 배지 `보장분석 · 맞춤설계 · 가족보장 · 든든한미래`.
- 팔레트: 크림·로즈 아이보리(`#FDF9F8`/`#FAF4F3`), 카드 `#FFFFFF`, 로즈 보더 `#EED9D8`, 포인트 로즈 코랄(`#D96B70`/`#C85A60`), 블러시 틴트 `#FDF0F0`, 깊은 와인/차콜(`#231F20`/`#3A2628`).
- 하트 리본 선화 로고 SVG + `보험에`(먹색)·`반하다`(로즈) 투톤 타이포를 헤더·메인 허브·고객 30장 표지·1·10·30장 PDF 표지/헤더에 적용.
- **시인성 철칙**: 와인·다크 카드 위 라벨은 `#FFFFFF`, 라이트 카드 위 글씨는 `#231F20` 유지. 5축/4축 레이더는 와인 패널 + 흰색 라벨 + 민트 데이터로 정리해 잘림·저대비를 없앴습니다.

### 3) 메인화면 설계사 실무 도우미 4종 (메뉴 9~12)
1. **🔍 질병코드·약관 사전** — 52개 핵심 KCD 코드(C73 갑상선, D00~D09 제자리, D37~D48 경계성, C44 기타피부, I20 협심증, I21 급성심근경색, I60~I62 뇌출혈, I63 뇌경색, I64, I65~I66, I67, I69, G45 TIA, M51 디스크, K63.5·D12 대장용종, H25 백내장, N18·K74·F00 등)를 코드·이름·증상 키워드로 즉시 검색. 지급 담보 / 확인 포인트 / 약관·판례 주의를 카드로 보여주고 코드 요약을 복사합니다.
2. **🏥 실손 세대별 비교·5세대 체크** — 1~5세대 급여·비급여 자기부담률·한도·재가입 비교표, 고객 세대 선택, 전환 판단 5기준, A 선택형 할인 특약 vs B 5세대 전환 비교, 5세대 확인 5가지.
3. **📋 고지사항·청구 서류 1탭 복사** — 3개월·1년·2·5년 체크로 일반고지/간편심사(3·2·5·3·5·5) 판정, 5대 담보+실손 청구 필수 서류를 카톡 문장으로 복사(개별·전체).
4. **💰 적정 보험료·리모델링 비교기** — 세후 월 소득 입력 → 권장 보장성 보험료 7~10%(상한 13%) 계산·게이지·판정, `A 현재 / B 같은 보험료 재배치 / C 소득 기준 권장까지` 세 카드의 등급·점수 전후 비교.
- 네 화면 모두 상·하단 `🏠 메인으로` 버튼이 있고, 고객 화면 모드에서는 자동으로 숨겨집니다.

## v4.2에서 달라진 것 — 메인 허브 + 한 화면 빠른 입력 + 5대 담보 실전 기준점 재정립

### 1) 메인 허브(홈)와 메인 복귀 버튼
- 앱을 열면 **메인 허브**가 먼저 나옵니다. 상단에 현재 선택된 고객 요약(이름·보험나이·보험료·실손·종합점수·계약 수)을 두고 `새 상담 시작` · `저장된 고객 불러오기` · `JSON 내보내기` · `JSON 가져오기` 버튼을 배치했습니다.
- 메뉴 카드 8종(1탭 이동): ① 상담자 상세 입력(6단계) ② **한 화면 빠른 입력(표 모드)** ③ 고객용 30장 프레젠테이션 ④ 라이브 상담(5단계) ⑤ PDF 리포트 저장·공유(1/10/30장) ⑥ 상담 이력·저장 목록 ⑦ 5대 담보 가이드 ⑧ 현장 툴킷.
- **모든 서브 화면 상단·하단에 `🏠 메인으로` 버튼**, 헤더에 상시 `🏠 메인` 버튼, 고객 30장 화면 우측 상단에 `🏠 메인` 버튼을 두었습니다. 탭바도 `메인·보장분석·라이브 상담·5대 담보·현장 툴킷` 5개로 정리했습니다.

### 2) 한 화면 빠른 입력(표 모드)
- 보장분석표를 보며 숫자·체크를 한 페이지에서 쭉 입력하는 실무용 고속 입력 뷰입니다. 위저드와 **같은 state**를 쓰므로 어느 쪽에서 고쳐도 카드 배지·점수·고객 30장·PDF에 즉시 반영됩니다.
- 항목마다 `직접입력` 숫자칸 + 빠른 선택 칩 + `권장` 금액을 한 줄에 두고, 금액 축은 판정(없음/최소 미달/최소 충족/권장 충족/충분)을 배지로 보여줍니다.

### 3) 5대 담보 실전 기준점 재정립
- **암**: 일반암 진단비 **최소 3,000 · 권장 5,000 · 충분 1억원**(전 연령 공통)과 3단계 게이지를 넣었습니다. 주요치료비 5종(암수술·항암약물·항암방사선·중환자실·비급여)은 그대로 유지했습니다.
- **뇌·심장**: 진단비 **최소 1,000 · 권장 2,000 · 3,000은 참고 상한(과권장 금지)**. 진단비가 1회성이라 **주요치료비 3종**을 신설했습니다 — ① 혈전용해제 치료비 ② 수술비(관혈·비관혈) ③ 중환자실 입원비(각 0 또는 500~3,000만원, 칩 `없음/1,000/2,000/3,000` + 직접입력).
- **수술비**: 질병 4축(질병수술비 일반·매회 / 질병 1~5종 / 질병 N대 / 비급여 질병 수술) + 상해 2축(일반 상해수술 / 상해 1~5종)으로 세분화했습니다. 단일 boolean을 금액 입력으로 바꿔 실제 가입금액을 그대로 적습니다.
- **간병비**: **일반병원(요양병원 제외) 일당 5~20만원**과 **요양병원 일당 0~20만원(통상 5~6만원대)**을 분리하고, 약관 요건 3가지를 선택형으로 받습니다 — ① 지급 기준 유형(시간 기준 일 8시간 / 금액 기준 일 7~8만원 / 무조건·미확인) ② 가족 간병 인정 여부(인정 / 업체등록·결제 필수 / 불인정) ③ 간호·간병통합서비스 일당(보유/없음). 장기요양등급은 그대로 둡니다.

### 4) 딥서치 검증을 반영한 실무 체크포인트
- **간병 지급 기준 전환(2026.7)**: 현대해상이 7월 1일부터 금액(하루 8만원) 기준을 시간(하루 8시간 연속) 기준으로 바꿨고, 한도 20만→15만원·보험료 10~20% 인상이 함께 이뤄졌습니다. 삼성화재는 요양병원 제외·8시간 기준, DB손보는 5월 26일 한도를 20만→15만원으로 낮췄고, 한화손보는 20만→10만원으로 축소했습니다. 업계 전반이 시간 기준으로 이동 중이며, 가족 간병은 업체 등록·결제·간병일지가 맞아야 인정됩니다. (한국보험신문 2026-06-29 · 중앙이코노미뉴스 2026-06-17/24 · 보험경제 2026-09-12 · 브릿지경제 2026-08-23)
- **혈전용해제 ≠ 혈전제거술**: 혈전용해 치료비는 뇌경색(I63)·급성심근경색(I21) 진단 후 혈전용해제(tPA 등)를 투여한 경우로, 약관상 **기계적 혈전제거술(카테터법)은 혈전용해치료에서 제외**됩니다. 별도 담보(예: 기계적혈전제거술 치료비)가 있는지 확인해야 하며, 대부분 **최초 1회한·연 1회한**이고 **계약일부터 1년 미만은 50% 감액**입니다. (삼성화재·현대해상·KB 약관 확인분)
- **수술비**: 5세대 실손의 비중증 비급여(연 1,000만원·자기부담 50%) 때문에 정액 비급여 수술비의 역할이 커졌고, 회사별 질환 묶음(용종·체외충격파 등)과 1년 미만 50% 감액 차이를 체크포인트로 넣었습니다.

### 세부 담보 입력
- **암**: 일반암 진단비 · 유사암(갑상선 C73·기타피부 C44·제자리 D00~D09·경계성 D37~D48) · **암 주요치료비 5종(암수술비 · 항암약물치료비 · 항암방사선치료비 · 중환자실 입원 · 비급여 추가 치료비, 각 500~3,000만원)** · 재진단·전이암 보장

- **심장(v5.0)**: 진단비 2단계 금액 — 허혈성심장질환 I20~I25(핵심·권장 2,000) / 급성심근경색 I21~I23 + **주요치료비 3종**. 협심증(I20) 미보장 여부를 자동 경고.
- **수술비**: 질병 4축(질병수술비 일반·매회 / 질병 1~5종 / 질병 N대 / 비급여 질병 수술) + 상해 2축(일반 상해수술 / 상해 1~5종)

- 보유 계약을 추가하면 10장 PDF 3페이지의 포트폴리오 표와 30장 2페이지 계약 표가 채워집니다. **납입중/납입완료**와 **만기(80·90세·100세·종신)**를 함께 적으면 10장 8페이지 노후 전망과 고객 슬라이드 4·27장에 반영됩니다.
- **가족력**은 암·뇌혈관·심장·치매를 중복 선택합니다. 선택한 가족력은 체크포인트·리포트·고객 슬라이드의 보완 우선순위 문장에 함께 나옵니다.
- **간편 고지 체크**는 3개월(진단·입원·수술) / 1년(추가검사) / 5년(입원·수술·7일 이상 치료·중대질병)을 터치하면 `표준체 → 3·5·5 → 3·2·5 → 3개월 경과 후 재검토 → 인수 심사 필요` 순서로 판정합니다. 판정은 상품별 청약서 문항이 최종 기준이라는 전제를 화면·PDF에 함께 적습니다.

- 설계사용 30장은 **가이드만 보고 따라가도 상담이 끊기지 않도록** 페이지마다 `이 페이지에서 할 일 → 판독 → 왜 → 질문 → 함정 → 설계 → 반론 → 동의 직후 멘트` 순서로 구성했습니다.
- 각 페이지 하단에는 **상담 메모란**(고객이 한 말 / 내가 약속한 것 / 다음 할 일)이 있어 출력해서 현장에서 바로 씁니다.

### PDF는 어떻게 만들어지나 (외부 라이브러리 0개)
1. 브라우저 Canvas에 A4(595×842pt) 레이아웃을 **시스템 한글 폰트**(Apple SD Gothic Neo → Pretendard → Noto Sans KR)로 150dpi(1240×1754px) 렌더링합니다.
2. 각 페이지를 JPEG로 만들고, 순수 JS로 **PDF 1.4 바이너리**(JPEG 이미지 XObject + 페이지 트리 + xref)를 조립합니다.
3. `Blob` → 모바일은 `navigator.share({files})`로 공유 시트, 그 외에는 즉시 다운로드.

이 방식이라 **한글이 절대 깨지지 않고**, 인터넷·서버·npm 패키지 없이 단일 HTML 파일에서도 그대로 동작합니다.

### 저장·공유
- **PC**: 클릭 즉시 `.pdf` 다운로드 (다운로드 폴더). 파일명은 `고객명_보장분석_1장요약_YYYYMMDD.pdf` 형식.
- **아이폰·안드로이드**: PDF가 준비되면 **공유하기(파일 앱 · 문자 · 카톡)** 또는 **기기에 저장**을 고릅니다. 공유 시트에서 바로 전송할 수 있습니다.
- 30장 플랜북은 약 5MB, 10장 상세는 약 1.8MB, 1장 요약은 약 0.3MB입니다.

## 진단 로직

- 5대 담보를 **세부 특약 단위 가중치**로 평가합니다(암: 일반암 55%·유사암 15%·주요치료비 5종 20%·재진단 10%, 뇌·심장: **진단비 3단계/2단계 55%**·주요치료비 3종 45%, 수술비: 6축, 간병비: 6칸).
- 뇌·심장 진단비는 **가장 넓은 범위(뇌혈관 I60~I69·허혈성 I20~I25)를 주축**으로 평가하고, 넓은 범위가 0원이면 좁은 범위에 부분 점수(뇌졸중 50%·뇌출혈 30%·급성심근경색 45%)만 부여합니다. 같은 진단에서 범위별 금액이 합산되는 구조를 그대로 반영합니다.
- **암 주요치료비 5종**은 세부별 충족도 `min(가입금액, 권장액)/권장액`을 권장 비중으로 가중해 하나의 충족도로 합칩니다(한 항목만 두꺼워도 다른 항목의 빈칸을 메우지 못합니다).
- 범위형 담보는 코드 범위로 점수를 매깁니다(뇌: 뇌출혈 0.45 < 뇌졸중 0.72 < 뇌혈관 1.0, 심장: 급성심근경색 0.45 < 허혈성 0.8 < 심장질환 1.0).
- `적정 / 보강 필요 / 공백 위험`은 대표 담보 존재 여부와 종합 충족도(90% 기준)로 판정합니다.
- **종합 점수** = 가중 평균(암 30·뇌 22·심장 18·수술비 15·간병비 15 기준, 연령대·직업급수로 가중 조정) − 감점(실손 공백 −8, 5세대 비중증 축소 −2, 갱신형 중심 −2). 상담 보조용 자체 산식입니다.
- **보장등급**은 점수를 A+~C 6단계로 옮긴 표기입니다(88↑ A+, 78↑ A, 68↑ B+, 58↑ B, 46↑ C+, 그 미만 C).
- 보험료 다이어트는 실손 세대, 갱신형·적립형·특약 수, 연 보험료 대비 핵심 진단비 배수, 가족력, 고지 판정, 계약 납입·만기로 체크포인트를 만듭니다.
- 고지 판정은 3개월 문항(진단·입원·수술) → 5년 중대질병 → 5년 입원·수술·7일 이상 치료 → 1년 추가검사 → 없음 순서로 내려가며, 간편심사 3·5·5는 N=5, 3·2·5는 N=2 구조를 따릅니다.
- 모든 수치는 상담 보조용이며, 실제 지급 여부·금액은 가입한 상품의 약관과 증권이 기준입니다.
