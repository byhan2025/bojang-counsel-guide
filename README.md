# 보장분석 · 5대 우선순위 상담 가이드

**라이브:** https://byhan2025.github.io/bojang-counsel-guide/
(아이폰 Safari로 열고 공유 → 홈 화면에 추가 → 주소창 없는 앱처럼 사용)

손해보험 설계사(FC)가 고객과 마주 앉아 화면을 보여주며 상담하는 모바일 웹앱(PWA)입니다.
빌드 도구 없이 Vanilla HTML/CSS/JS로 동작하고, 홈 화면에 추가하면 앱처럼 열립니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 📋 보장분석 | 고객 정보 입력 → **종합 보장 밸런스 점수(100점)** + 5대 우선순위 충족도 게이지, 보장 구멍·보험료 다이어트 체크(상담자 전용), 리모델링 3단계, **고객 카톡 요약 복사**, **최근 상담 5건 저장/불러오기** |
| 🎯 5대 담보 | 1.암 → 2.뇌 → 3.심장 → 4.수술비 → 5.간병비. 담보별 **SVG 도식**(포함관계·구조 비교) + 4단 아코디언(보장 범위 · 1분 설명 화법 · 증권 함정 · 청구 주의) |
| ⚡ 현장 툴킷 | 고지의무 3·1·5 체크표, 간편심사 3·2·5 비교, 실손 1~5세대 비교(모바일 카드 / 와이드 표), 2026.11 개편, 반론 돌파 화법(공감→환기→대안) |

### 상담자 뷰 / 고객 공유 뷰
상단 스위치로 전환합니다. **고객 공유 뷰**에서는 내부 요소(증권 함정, 보험료 다이어트, 반론 화법, 현장 툴킷 탭, 상담 이력)가 숨고
**점수·게이지·보장 범위 도식·리모델링 로드맵·청구 안내**만 남습니다. 선택은 기기에 저장됩니다.

## 파일

```
index.html      화면 구조
styles.css      디자인(네이비·골드·민트, 모바일 퍼스트)
content.js      상담 콘텐츠 데이터(담보 가이드·고지의무·실손 세대·반론 화법·가중치 모델)
app.js          점수 산식·진단 로직·SVG 도식·렌더링·복사·이력 저장
manifest.json   PWA 매니페스트
sw.js           서비스 워커(앱 셸 캐시 → 오프라인 동작)
icons/          앱 아이콘(192·512·maskable·apple-touch)
build_single.py 단일 파일 번들 생성기 → dist/bojang-guide.single.html
```

## 진단 로직

- 5대 담보 권장선(연령대별) 대비 보유 금액으로 `적정 / 보강 필요 / 공백 위험`을 판정합니다.
- 수술비는 5종 수술비 금액 + N대 수술비 보유, 간병비는 간병인 사용일당 + 장기요양 보장 보유를 함께 봅니다(미보유 시 충족도 20% 감액).
- **종합 점수** = 가중 평균(암 30·뇌 22·심장 18·수술비 15·간병비 15 기준, 연령대·직업급수로 가중 조정) − 감점(실손 공백 −8, 5세대 비중증 축소 −2, 갱신형 중심 −2). 상담 보조용 자체 산식입니다.
- 보험료 다이어트는 실손 세대, 갱신형·적립형·특약 수, 연 보험료 대비 핵심 진단비 배수로 체크포인트를 만듭니다.
- 모든 수치는 상담 보조용이며, 실제 지급 여부·금액은 가입한 상품의 약관과 증권이 기준입니다.

## 실행

```bash
python3 -m http.server 8765      # http://localhost:8765
python3 build_single.py          # 단일 HTML 생성 → dist/bojang-guide.single.html
```

## 아이폰·아이패드 홈 화면 추가

1. Safari로 배포 주소를 엽니다.
2. 하단 **공유** → **홈 화면에 추가** → 이름 확인 후 **추가**.
3. 홈 화면 아이콘으로 열면 주소창 없는 앱 화면으로 뜨고, 한 번 열면 오프라인에서도 열립니다.
