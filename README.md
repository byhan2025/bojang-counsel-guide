# 보장분석 라이프 리포트 v5.4 (베타) · 고객 맞춤형 보장 점검 · 리모델링 상담 가이드

**라이브:** https://byhan2025.github.io/bojang-counsel-guide/
(아이폰 Safari로 열고 공유 → 홈 화면에 추가 → 주소창 없는 앱처럼 사용)

설계사가 고객과 마주 앉아 화면을 보여주며 상담하는 모바일 웹앱(PWA)입니다.
빌드 도구 없이 Vanilla HTML/CSS/JS로 동작하고, 홈 화면에 추가하면 앱처럼 열립니다.

## v5.4에서 달라진 것 — 백엔드 패키지 · 로그인/구독 · 사진 AI 인식 연동

### 1) Supabase 백엔드 패키지 `supabase/` (즉시 배포 가능)
- `migrations/001_initial_schema.sql` — `profiles` · `subscriptions` · `clients` · `brand_settings` · `audit_logs` 5개 테이블,
  **RLS 정책**(본인 행만 · 구독 쓰기는 service_role 만 · `billing_key` 컬럼 권한 차단) · **updated_at 트리거** · `is_pro()` 함수 · 가입 시 프로필 자동 생성 트리거.
- `functions/parse-coverage-vision` — **Deno Edge Function**. JWT 검증 → multipart/base64 이미지(최대 10MB) → **저장 없이 메모리에서만** OpenAI/Gemini Vision 호출 → v5.3 `parseCoverageText`와 호환되는 표준 JSON(`text`·`items`·`premium`·`silson`·`model`·`ms`) 반환 → 버퍼·base64 참조 즉시 `null` · `Cache-Control: no-store` · CORS · 사용자당 분당 6회 제한 · 주민번호/전화 마스킹.
- `functions/billing-subscribe` — 월 **5,000원** / 연 **50,000원**. 금액은 서버 상수만 신뢰(클라이언트 금액 무시). 토스페이먼츠 빌링키 발급 + 첫 결제, 포트원 V2 결제 검증(2순위), `BILLING_TEST_MODE=true` 테스트 모드.
- `functions/billing-webhook` — 토스/포트원 **HMAC 서명 검증**, `audit_logs.dedupe_key` 기반 **멱등**, 구독 상태 동기화(성공→active·기간 연장 / 실패→past_due / 해지·환불→canceled).
- `config.toml` + `DEPLOY.md` — `supabase link → db push → functions deploy` 1분 명령과 **환경변수 체크리스트**.

### 2) 앱 연동 레이어 `backend.js` (외부 SDK·CDN 없음)
- `fetch` 만으로 Supabase **Auth**(회원가입·로그인·로그아웃·토큰 자동 갱신) · **PostgREST**(`clients`·`brand_settings` 동기화, `subscriptions` 조회) · **Edge Function** 호출.
- 설정이 비어 있으면 자동 **`mode: 'beta-local'`**(v5.3과 동일 동작·외부 요청 0), 값이 채워지거나 개발자 설정 패널의 연결 테스트를 통과하면 **`mode: 'live-backend'`**.
- **👤 계정 / 구독** 버튼(헤더 고객 스트립 + 메인 허브) → 로그인·회원가입 탭, 서버 연결 상태 칩, 구독 상태, 월 5,000원/연 50,000원 플랜 선택, 개발자 설정(URL·anon key 저장·연결 테스트) 모달.
- 연결 전에는 **“현재 베타 오프라인 모드 · 서버 연결 시 클라우드 동기화 및 AI 사진 인식이 활성화됩니다”** 를 안내하고, 폼 동선은 그대로 확인할 수 있습니다(입력값은 전송·저장되지 않음).

### 3) 사진 → AI 인식 → 검수 화면
- 서버 연결 + 로그인 상태에서 사진을 찍으면 `parseWithVisionBackend` → `backend.js.parseCoverageVision` → Edge Function으로 전송하고,
  응답 텍스트를 **같은 `parseCoverageText` 검수 화면**(담보명·금액·근거 원문)에 넣습니다. 사진은 전송 후 참조를 즉시 버립니다.
- 미연결이면 v5.3의 정적 베타 안내(해상도·대비 + 한계 고지)를 그대로 유지합니다.

## v5.3에서 달라진 것 — 자동입력 허브 · 사진 즉시 촬영(휘발) · 보장분석 PDF 로컬 추출

### 1) 입력 방식 선택 허브 (새 상담 시작 · 입력실 상단)
- 메인 **`새 상담 시작`** 을 누르면 **`어떻게 입력할까요?`** 허브가 먼저 열립니다. 6단계 입력실·한 화면 빠른 입력 상단의 **`✎ 입력 방식`** 버튼과 위저드 상단에서도 같은 허브를 엽니다.
- 세 가지를 고릅니다: **① 수기 입력**(6단계 입력실 / 한 화면 빠른 입력 표 모드) · **② 사진 즉시 촬영(휘발·미저장)** · **③ 보장분석 PDF·텍스트(100% 로컬 추출)**.

### 2) 사진 즉시 촬영 — 앨범 선택 없이, 찍고 바로 파기
- 촬영 버튼은 `<input type="file" accept="image/*" capture="environment">` 로 **카메라를 바로 호출**하며, 앨범 선택 단계가 없습니다. `getUserMedia` 기반 **앱 내 카메라**(전/후면)도 대안으로 제공합니다.
- 촬영 전 보안 고지: **“이름·주민등록번호 등 민감정보는 가리고 담보표만 촬영해 주세요. 촬영된 사진은 기기·서버 어디에도 저장되지 않고 분석 직후 메모리에서 즉시 파기됩니다.”**
- 처리 후 `URL.revokeObjectURL` · canvas `width=height=0` · ImageBitmap `close()` · Blob 참조 해제를 수행하고 **`원본 사진 메모리 파기 완료 ✓ (저장 기록 0건)`** 배지를 표시합니다. `localStorage` · `sessionStorage` · `IndexedDB` · 서버 업로드는 **한 번도 쓰지 않습니다**(테스트로 검증).
- 정적 베타에서는 AI 비전 서버가 없으므로 자동 숫자 추출을 하지 않고, **해상도·대비 전처리 결과와 정직한 한계 안내**를 보여줍니다. 3단계 백엔드 연결용 **`parseWithVisionBackend(blob, endpoint)`** 어댑터를 `import-parser.js`에 준비했습니다(`VISION_ENDPOINT` 값만 채우면 동작).

### 3) 보장분석 PDF · 텍스트 로컬 추출 (`import-parser.js`)
- 외부 라이브러리·CDN 없이 **`file://` 에서도 100% 동작**하는 경량 PDF 텍스트 추출기:
  `DecompressionStream('deflate')` 기반 **FlateDecode** 해독, 괄호 리터럴·16진 문자열, **UTF-16BE / PDFDocEncoding / UTF-8**, Type0(CID) 폰트의 **ToUnicode CMap(bfchar·bfrange)**, PDF 1.5 **오브젝트 스트림(ObjStm)** 확장.
- **글자가 없는 이미지 스캔 PDF**는 “이미지 N개 · 추출 글자 0자”로 정직하게 안내하고 텍스트 붙여넣기로 되돌립니다. 폰트 매핑이 없어 깨진 경우도 경고합니다.
- **한국 보장분석표 파서(`parseCoverageText`)**: 정규식 + 동의어 사전 + 섹션 문맥(암·뇌·심장·수술·간병)으로 v5.2 모델 필드에 매핑합니다.
  월 보험료 · 실손 세대(1~5) · 일반/유사/고액암 · 암 주요치료비 5종 · 뇌 3단계 + 치료비 3종 · 심장 2단계 + 치료비 3종 · 질병/상해 수술비 4+2축 · 일반/요양 간병 일당.
  금액은 **`3,000만원` · `3천만원` · `1억원` · `500만` · `270,000원` · `1억 2,000만원`** 을 모두 **만원 단위**로 정규화합니다.
- **검수 화면**: 인식 항목을 `담보명 · 인식 금액 · 매칭 근거 원문`으로 보여주고, 체크박스와 숫자 수정칸으로 고친 뒤 **`[선택 항목 입력칸에 반영]`** 을 누르면 현재 고객 상태에 반영되고 점수를 다시 계산해 6단계 입력실/리포트로 이동합니다.
- **`샘플 보장분석표 불러오기`** 버튼으로 20개 담보가 든 표준 표를 즉시 시험할 수 있습니다.

- 각 페이지 하단에는 **상담 메모란**(고객이 한 말 / 내가 약속한 것 / 다음 할 일)이 있어 출력해서 현장에서 바로 씁니다.

### PDF는 어떻게 만들어지나 (외부 라이브러리 0개)
1. 브라우저 Canvas에 A4(595×842pt) 레이아웃을 **시스템 한글 폰트**(Apple SD Gothic Neo → Pretendard → Noto Sans KR)로 150dpi(1240×1754px) 렌더링합니다.
2. 각 페이지를 JPEG로 만들고, 순수 JS로 **PDF 1.4 바이너리**(JPEG 이미지 XObject + 페이지 트리 + xref)를 조립합니다.
3. `Blob` → 모바일은 `navigator.share({files})`로 공유 시트, 그 외에는 즉시 다운로드.

이 방식이라 **한글이 절대 깨지지 않고**, 인터넷·서버·npm 패키지 없이 단일 HTML 파일에서도 그대로 동작합니다.

### 저장·공유
- **PC**: 클릭 즉시 `.pdf` 다운로드 (다운로드 폴더). 파일명은 `고객명_보장분석_1장요약_YYYYMMDD.pdf` 형식.
- **아이폰·안드로이드**: PDF가 준비되면 **공유하기(파일 앱 · 문자 · 카톡)** 또는 **기기에 저장**을 고릅니다. 공유 시트에서 바로 전송할 수 있습니다.
- 30장 플랜북은 약 5MB, 10장 상세는 약 1.8MB, 1장 요약은 약 0.3MB입니다.

## 진단 로직

- 5대 담보를 **세부 특약 단위 가중치**로 평가합니다(암: 일반암 55%·유사암 15%·주요치료비 5종 20%·재진단 10%, 뇌·심장: **진단비 3단계/2단계 55%**·주요치료비 3종 45%, 수술비: 6축, 간병비: 6칸).
- 뇌·심장 진단비는 **가장 넓은 범위(뇌혈관 I60~I69·허혈성 I20~I25)를 주축**으로 평가하고, 넓은 범위가 0원이면 좁은 범위에 부분 점수(뇌졸중 50%·뇌출혈 30%·급성심근경색 45%)만 부여합니다. 같은 진단에서 범위별 금액이 합산되는 구조를 그대로 반영합니다.
- **암 주요치료비 5종**은 세부별 충족도 `min(가입금액, 권장액)/권장액`을 권장 비중으로 가중해 하나의 충족도로 합칩니다(한 항목만 두꺼워도 다른 항목의 빈칸을 메우지 못합니다).
- 범위형 담보는 코드 범위로 점수를 매깁니다(뇌: 뇌출혈 0.45 < 뇌졸중 0.72 < 뇌혈관 1.0, 심장: 급성심근경색 0.45 < 허혈성 0.8 < 심장질환 1.0).
- `적정 / 보강 필요 / 공백 위험`은 대표 담보 존재 여부와 종합 충족도(90% 기준)로 판정합니다.
- **종합 점수** = 가중 평균(암 30·뇌 22·심장 18·수술비 15·간병비 15 기준, 연령대·직업급수로 가중 조정) − 감점(실손 공백 −8, 5세대 비중증 축소 −2, 갱신형 중심 −2). 상담 보조용 자체 산식입니다.
- **보장등급**은 점수를 A+~C 6단계로 옮긴 표기입니다(88↑ A+, 78↑ A, 68↑ B+, 58↑ B, 46↑ C+, 그 미만 C).
- 보험료 다이어트는 실손 세대, 갱신형·적립형·특약 수, 연 보험료 대비 핵심 진단비 배수, 가족력, 고지 판정, 계약 납입·만기로 체크포인트를 만듭니다.
- 고지 판정은 3개월 문항(진단·입원·수술) → 5년 중대질병 → 5년 입원·수술·7일 이상 치료 → 1년 추가검사 → 없음 순서로 내려가며, 간편심사 3·5·5는 N=5, 3·2·5는 N=2 구조를 따릅니다.
- 모든 수치는 상담 보조용이며, 실제 지급 여부·금액은 가입한 상품의 약관과 증권이 기준입니다.
