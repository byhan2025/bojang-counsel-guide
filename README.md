# 보장분석 상담 가이드 v3

**라이브:** https://byhan2025.github.io/bojang-counsel-guide/
(아이폰 Safari로 열고 공유 → 홈 화면에 추가 → 주소창 없는 앱처럼 사용)

손해보험 설계사(FC)가 고객과 마주 앉아 화면을 보여주며 상담하는 모바일 웹앱(PWA)입니다.
빌드 도구 없이 Vanilla HTML/CSS/JS로 동작하고, 홈 화면에 추가하면 앱처럼 열립니다.

## v3에서 달라진 것

- **인쇄(window.print) 제거** → 앱 안에서 실제 `.pdf` 파일을 직접 만듭니다. 서버·외부 라이브러리 0개.
- **PDF 3종**: 고객용 **1장 요약**, 고객용 **10장 상세**, 설계사용 **30장 상담 플랜북**.
  생성된 파일은 PC에서 바로 다운로드되고, 아이폰·안드로이드에서는 공유 시트로 **파일 앱 저장 · 문자 · 카카오톡** 전송이 가능합니다.
- **라이브 상담 모드** 탭: `오프닝 → 진단 설명 → 우선순위 플랜 → 반론 돌파 → 클로징` 5단계를 화면으로 넘기며 상담합니다. 단계별 타이머 포함.
- **고객 정보 입력**: 고객명, 생년월일(보험나이·상령일 D-day 자동 계산), 담당 컨설턴트, **보유 계약 목록**(보험사·상품명·월 보험료·갱신 여부).
- 1장·10장·30장 PDF의 모든 수치는 입력값으로 계산되어 고객별로 달라집니다.

## 화면

| 탭 | 내용 |
| --- | --- |
| 📋 보장분석 | **5단계 터치 위저드**(고객·기본정보 → 암 → 뇌·심장 → 수술·간병 → 계약·보험료) → 종합 보장등급(A+~C)·5각 레이더·5대 진단·**PDF 3종 저장/공유**·카톡 요약 복사·최근 상담 5건 |
| 🎧 라이브 상담 | 오프닝 → 진단 설명 → 우선순위 플랜 → 반론 돌파 → 클로징. 단계별 스크립트·질문·함정·설계안·반론 6종·타이머 |
| 🎯 5대 담보 | 1.암 → 2.뇌 → 3.심장 → 4.수술비 → 5.간병비. SVG 도식(포함관계·구조 비교) + 4단 아코디언(보장 범위 · 1분 설명 화법 · 증권 함정 · 청구 주의) |
| ⚡ 현장 툴킷 | 고지의무 3·1·5 체크표, 간편심사 3·2·5 비교, 실손 1~5세대 비교, 2026.11 개편, 반론 돌파 화법(공감→환기→대안) |

### 세부 담보 입력
- **암**: 일반암 진단비 · 유사암(갑상선 C73·기타피부 C44·제자리 D00~D09·경계성 D37~D48) · 암 주요치료비(표적·면역·비급여) · 재진단·전이암 보장
- **뇌**: 보장 범위 선택(미보유 / 뇌출혈 I60~I62 / 뇌졸중 I60~I64 / 뇌혈관질환 I60~I69) + 뇌혈관 수술·혈전용해치료비
- **심장**: 보장 범위 선택(미보유 / 급성심근경색 I21~I22 / 허혈성심장 I20~I25 / 심장질환·부정맥) + 심혈관 수술비
- **수술비**: 질병 1~5종(5종 기준액) + N대 질병수술비 + 상해수술비
- **간병비**: 간병인 사용일당(일반형/체증형) + 간호간병통합서비스 + 장기요양등급(1~5·인지지원)

### 고객 정보·보험나이
- 생년월일을 입력하면 **보험나이**(만 나이 + 6개월 이상이면 +1)와 **상령일**(생일 + 6개월) D-day를 계산해 상단에 표시합니다.
- 상령일이 지나면 보험나이가 올라가 같은 보장도 보험료가 달라질 수 있어, PDF 8페이지·30장 2페이지에 남깁니다.
- 보유 계약을 추가하면 10장 PDF 3페이지의 포트폴리오 표와 30장 2페이지 계약 표가 채워집니다.

## PDF 3종

| 종류 | 페이지 | 구성 |
| --- | --- | --- |
| 고객용 1장 요약 | **1** | 고객 정보 · 보장등급(A+~C)·점수 · 종합 도넛(충분/점검/부족/없음) · 5대 우선순위 표(현재/권장/판정/부족분) · 핵심 보장 요약 · 실행 로드맵 3단계 |
| 고객용 10장 상세 | **10** | 01 표지·목차 / 02 진단 결과(도넛·KPI·진단 3종·보험료 배분·5대 요약) / 03 포트폴리오(계약 표·세부 매트릭스·다음 과제) / 04 밸런스(4축 레이더·우선 점검 5) / 05 암 정밀 / 06 뇌·심장 범위(동심원·코드 표·통계) / 07 수술·입원·간병·실손(방어력 4축·장기요양 분포) / 08 갱신형·노후(전망·대응 3단계·상령일) / 09 보장자산 Summary(14항목 점수·요약표·지표) / 10 보조보장·로드맵 |
| 설계사용 30장 플랜북 | **30** | 01 페이지 지도 / 02 프로파일·예상 쟁점 / 03 오프닝 / 04 전체 판독 / 05 순서 근거 / 06 보험료 다이어트 / 07~11 암 / 12~15 뇌 / 16~19 심장 / 20~22 수술비 / 23~25 간병·장기요양 / 26 실손 전환 매뉴얼 / 27 고지의무 / 28 6대 거절 돌파 / 29 클로징 3단계 / 30 사후관리·소개 |

- 설계사용 30장은 **가이드만 보고 따라가도 상담이 끊기지 않도록** 페이지마다 `이 페이지에서 할 일 → 판독 → 왜 → 질문 → 함정 → 설계 → 반론 → 동의 직후 멘트` 순서로 구성했습니다.
- 각 페이지 하단에는 **상담 메모란**(고객이 한 말 / 내가 약속한 것 / 다음 할 일)이 있어 출력해서 현장에서 바로 씁니다.

### PDF는 어떻게 만들어지나 (외부 라이브러리 0개)
1. 브라우저 Canvas에 A4(595×842pt) 레이아웃을 **시스템 한글 폰트**(Apple SD Gothic Neo → Pretendard → Noto Sans KR)로 150dpi(1240×1754px) 렌더링합니다.
2. 각 페이지를 JPEG로 만들고, 순수 JS로 **PDF 1.4 바이너리**(JPEG 이미지 XObject + 페이지 트리 + xref)를 조립합니다.
3. `Blob` → 모바일은 `navigator.share({files})`로 공유 시트, 그 외에는 즉시 다운로드.

이 방식이라 **한글이 절대 깨지지 않고**, 인터넷·서버·npm 패키지 없이 단일 HTML 파일에서도 그대로 동작합니다.

### 저장·공유
- **PC**: 클릭 즉시 `.pdf` 다운로드 (다운로드 폴더). 파일명은 `고객명_보장분석_1장요약_YYYYMMDD.pdf` 형식.
- **아이폰·안드로이드**: PDF가 준비되면 **공유하기(파일 앱 · 문자 · 카톡)** 또는 **기기에 저장**을 고릅니다. 공유 시트에서 바로 전송할 수 있습니다.
- 30장 플랜북은 약 5MB, 10장 상세는 약 1.8MB, 1장 요약은 약 0.3MB입니다.

## 진단 로직

- 5대 담보를 **세부 특약 단위 가중치**로 평가합니다(암: 일반암 55%·유사암 15%·주요치료비 20%·재진단 10%, 뇌·심장: 범위 70%·수술/치료비 30%, 수술비: 5종 50%·N대 30%·상해 20%, 간병비: 일당 45%·간호간병 25%·장기요양 30%).
- 범위형 담보는 코드 범위로 점수를 매깁니다(뇌: 뇌출혈 0.45 < 뇌졸중 0.72 < 뇌혈관 1.0, 심장: 급성심근경색 0.45 < 허혈성 0.8 < 심장질환 1.0).
- `적정 / 보강 필요 / 공백 위험`은 대표 담보 존재 여부와 종합 충족도(90% 기준)로 판정합니다.
- **종합 점수** = 가중 평균(암 30·뇌 22·심장 18·수술비 15·간병비 15 기준, 연령대·직업급수로 가중 조정) − 감점(실손 공백 −8, 5세대 비중증 축소 −2, 갱신형 중심 −2). 상담 보조용 자체 산식입니다.
- **보장등급**은 점수를 A+~C 6단계로 옮긴 표기입니다(88↑ A+, 78↑ A, 68↑ B+, 58↑ B, 46↑ C+, 그 미만 C).
- 보험료 다이어트는 실손 세대, 갱신형·적립형·특약 수, 연 보험료 대비 핵심 진단비 배수로 체크포인트를 만듭니다.
- 모든 수치는 상담 보조용이며, 실제 지급 여부·금액은 가입한 상품의 약관과 증권이 기준입니다.

## 아이폰·아이패드 홈 화면 추가

1. Safari로 배포 주소를 엽니다.
2. 하단 **공유** → **홈 화면에 추가** → 이름 확인 후 **추가**.
3. 홈 화면 아이콘으로 열면 주소창 없는 앱 화면으로 뜨고, 한 번 열면 오프라인에서도 열립니다.
